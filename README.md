# Laboratorio de Programación Aplicada — Lección 2

Aplicación estática preparada para GitHub Pages. Replica el diseño, dinámica y funcionamiento del laboratorio de la Lección 1, pero con 30 retos construidos exclusivamente a partir del material del estudiante de la Lección 2.

## Contenido evaluado
- Funciones y modularidad.
- Parámetros y `return`.
- Listas y diccionarios.
- Listas de diccionarios y conexión conceptual con Excel.
- Programación Orientada a Objetos: clase, objeto, atributo y método.

## Archivos
- `index.html`: interfaz principal.
- `styles.css`: diseño, animaciones y adaptación móvil.
- `app.js`: lógica de los 30 retos, cronómetro, retroalimentación y mejor resultado.
- `assets/`: carpeta de recursos, conservada con la misma estructura del laboratorio original.

## Publicar en GitHub Pages
1. Cree un repositorio nuevo en GitHub.
2. Suba `index.html`, `styles.css`, `app.js` y la carpeta `assets`.
3. Vaya a Settings > Pages.
4. En Build and deployment seleccione Deploy from a branch.
5. Seleccione la rama `main` y la carpeta `/ (root)`.
6. Guarde y espere a que GitHub publique el sitio.

No requiere servidor, Python, Streamlit ni base de datos.
El mejor resultado de la Lección 2 se guarda localmente en el navegador mediante `localStorage`, separado del registro de la Lección 1.
